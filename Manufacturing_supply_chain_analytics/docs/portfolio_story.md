# Portfolio Story

### Situation
Operations leaders have fragmented signals across procurement, plants, warehouses, logistics, machine events and quality.

### Task
Create a trusted analytical layer that identifies operational risk and explains likely drivers rather than only displaying KPI totals.

### Action
Profiled source data, quantified data-quality defects, investigated performance with SQL, created reusable dbt transformations, designed a Power BI semantic model and connected production, machine and quality signals for root-cause analysis.

### Result
A reproducible enterprise-style analytics framework that can be refreshed at scale and used to prioritise supplier intervention, inventory action, plant reliability work, logistics improvement and data-quality remediation.
