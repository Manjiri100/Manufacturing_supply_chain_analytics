# Project Inventory — Manufacturing & Supply Chain Analytics

## Portfolio purpose
Enterprise-style analytics project covering procurement, inventory, production, logistics, quality and machine events.

## Dataset scale
19,275,600 synthetic records across 11 tables. Full data is generated locally and intentionally excluded from GitHub.

## Core deliverables
- Python data generator
- Representative sample CSVs
- SQL investigation scripts
- dbt staging, intermediate and mart models
- Data-quality tests and strategy
- Power BI semantic model, measures and wireframe
- Architecture, business questions, data dictionary and portfolio story
- GitHub Actions quality workflow
